## 数据说明
在线版的数据保存在**你自己的浏览器**里（localStorage），不上传任何服务器。
换电脑或换浏览器，请用「备份中心 → 导出整库 JSON」搬数据。
需要多人共享同一份数据，请用本地全栈版（仓库源码里的 server.cjs）。

## 与本地全栈版的区别
