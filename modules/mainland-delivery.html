一、计费公式（精简版，只保留五个主要远洋港）

来源：CRM au-model.mjs（AU_MODEL v7.0）
本版按你的实际业务收敛为 悉尼 Port Botany / 墨尔本 / 布里斯班 / 阿德莱德 / 弗里曼特尔 五大远洋集装箱港，去掉区域港/支线港的复杂规则，只保留主港最近匹配。公式仍沿用 CRM 同源模型的“基础拖车 + 幂律里程 + 燃油 + 码头固定费 + 附加 + 毛利/GST”结构。
基础拖车费 = (侧卸 ? cartSL : cartStd) × 柜型系数 里程费 = ∫[25km→km] kmRate × (x/100)^(-0.5) dx = kmRate × 200 × [ √(km/100) − 0.5 ] （100km 处单价 = kmRate，越远越便宜） 燃油附加 = (基础拖车费 + 里程费 + 偏远尾板) × FSC%（城市 / 偏远档） 码头固定费 = 终端接入费 + VBS + 能源附加 + 过路/拥堵（按港固定） 附加作业 = 等待 / 周六日 / 检疫 / 超重 / 改期等（按勾选与条件触发） 空箱返还 = 按港默认，可勾选“不含” 成本小计 = 上述合计 净成本 = 成本小计 × 季节因子（淡 0.92 / 正常 1.00 / 旺 1.18） 对外报价 = 净成本 ÷ (1 − 毛利率) × (1 + GST 10%)
柜型系数：标准车 20GP 0.72 / 40GP 0.96 / 40HQ 1.00；侧卸车 0.80 / 0.98 / 1.00。偏远判定：里程 > 60km 或手动勾选。

五、模型校验与边界

  • 校验：38 个真实报价/官方费率点位 命中 38/38 = 100%，平均绝对误差 1.05%；CITO Kingsgrove 2208 整单 A$1,530.84 精确复现；v7 实测对外报价（40HQ 侧卸、含 12% 毛利）悉尼/墨尔本/布里斯班/阿德莱德/弗里曼特尔等 8 条 0% 偏差复现（2208 $1,740、4000 $1,590、5000 $1,533、6065 $2,263 等）。
  • 覆盖：2,696 个街道邮编（NSW/ACT 2xxx、VIC 3xxx、QLD 4xxx、SA 5xxx、WA 6xxx）；2,696 × 5 = 13,480 条 OSRM 真实公路里程。
  • 只按五大港：昆士兰北部（凯恩斯/汤斯维尔/麦凯）与西澳北部（黑德兰/布鲁姆/丹皮尔）距最近主港 1,200–3,400km，模型会标“超长途”，实际业务建议铁路/沿海支线/当地拆柜或改用区域港人工询价。
  • 不含：国际海运费、出口费用、关税/保险、海关查验实报、码头超期堆存、船司滞箱（未填天数时）、吊车台班超出部分、二次派送、转运/拆柜。
  • 时效：码头终端费/VBS/燃油为 2026-10 数据；正式报价前请核对当周数值，报价有效期建议 7 天。输出为估算辅助，不构成承运人正式报价。
