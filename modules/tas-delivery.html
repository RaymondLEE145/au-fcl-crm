一、计费公式（本工具使用的算法模型）

可复现 · 可调参 · 每项均有来源或明确假设
含税总价 = ( A + B + C + D + E ) × (1 + GST) A 海运与港口段 A1 塔州码头操作/吊装费 = 按柜型固定值（20ft / 40ft） A2 TasPorts Wharfage = 官方费率 × TEU （直航 106.45/TEU；Bass Strait 高频船东 67.47/TEU；40ft 计 2 TEU） A3 Bass Strait 海运费 = 仅“墨尔本中转”路径：20ft / 40ft 市场基准 A4 冷藏柜插电 = 73.07/天 × 港口天数（TasPorts 官方） A5 检疫熏蒸/清洗 = 可选，362 起（TasPorts 官方） A6 港口超期仓储 = 超期天数 × 日费率 B 派送段（wharf cartage） B1 基础派送费 = 按柜型固定值（已含首个 25 km） B2 超里程费 = max(0, 公路里程 − 25) × 每公里单价 B3 区域附加 = (B1 + B2) × 偏远系数（60–120km 4% / 120–220km 10% / >220km 18%） B4 现场作业附加 = 侧卸 / 吊车 / 转运 / 未铺装路 / CBD / 周末与夜间 B5 等待费 = max(0, 等待小时 − 1h) × 小时费率 C 空箱与时间费 C1 空箱返还（dehire） = 按柜型固定值（空箱拖回指定堆场） C2 滞箱费（detention） = max(0, 占用天数 − 免费天数) × 日费率 C3 超重附加 = max(0, 毛重 − 公路限重) × 每吨费率 D 燃油附加 D1 燃油附加 = 燃油率（市区/偏远分档：>60km 用偏远档）× (B1 + B2 + B3 + B4 + B5) E 加价与其他 E1 报价加价 = 成本小计 × 加价率（可选，默认 0；用于把成本价转成对外报价） E2 地磅 / 特殊许可 / POA 项（默认 0，按需勾选） 区间：海运费 ×0.85~1.20；派送费 ×0.90~1.12；附加作业 ×0.90~1.10；官方固定费不浮动。 判定：硬性阻断（岛屿/无路）→ ⛔ 不可整柜；需附加条件（侧卸/转运/许可/超重/偏远40ft）→ ⚠️ 可派送但受限；否则 ✅ 可整柜直达。
为什么用“分区/里程”而不是单一邮编价？ 塔州实际派送市场以“基础价（含 25 km 左右）+ 超出里程单价 + 偏远/作业附加”计价，且港口到客户的公路里程是成本主因（司机工时 + 燃油 + 空箱回程）。本模型用 OSRM 公路路由计算 4 大港口到每个邮编的真实里程，再套用市场费率结构，因此任意邮编都能给出一致、可解释的报价。

四、数据来源与市场依据

  • TasPorts《Schedule of Port Charges》（2026-07-01 生效，FY2027） — Wharfage：满载箱 106.45 澳元/TEU（King/Flinders 132.18），空箱 30.35/TEU；Bass Strait 高频船东：满载 67.47/TEU、空箱 0；冷藏柜插电 73.07/天；熏蒸 362/箱；地磅 13.30/次；King Island 侧卸设备 150/小时等。tasports.com.au/port-charges
  • Bass Island Line《Freight Tariff FY2027》（2026-09-01 至 2027-06-30） — King Island 航线 20ft 集装箱 Devonport↔King Island 2,147 澳元（含 GST/港口费/燃油附加），重箱 2,370；40ft 为 POA；此费率用于本工具“岛屿不可整柜直达”的替代方案估算。bassislandline.com.au/freight-tariff
  • Strait Link Shipping — 墨尔本–伯尼每日滚装，经营 FCL/冷藏柜/拖车，塔州内有 Hobart / Launceston / Devonport / Burnie 堆场，提供全塔州 door-to-door；本工具“墨尔本中转”路径按此模式建模。straitlink.com.au/our-services
  • Spirit of Tasmania（TT-Line）Freight — 墨尔本（吉朗）–德文波特滚装，塔州约 20% 跨海货运量；本工具中 Devonport 到港口径按其码头（East Devonport）建模。spiritoftasmania.com.au
  • Fruit Growers Tasmania《Bass Strait Freight Workshop》 — 引用 Tasmanian Freight Equalisation Scheme（TFES）标准：国内货运最高补贴 855 澳元/TEU（进出口中转运 700 澳元/TEU）；该数值从侧面印证跨海单 TEU 海运费量级，本工具默认 Bass Strait 海运价即以此为锚并叠加港口操作与市场溢价。fruitgrowerstas.org.au（PDF）
  • Tasmanian sea freight task（塔州政府信息文件） — 跨海货运结构、港口与航线背景。infrastructure.tas.gov.au（PDF）
  • 公路里程 — 使用 OSRM 公开路由引擎（OpenStreetMap 路网）计算 4 个港口到每个邮编代表城镇的实际驾车里程与时长；邮编代表点优先采用 GeoNames 人口最大的城镇坐标（避免邮编几何中心落在无人区）。
  • 澳洲燃油附加（FSC）基准 — GPSM 2026-06 卡车燃油附加指数：NSW/VIC 26%、QLD/WA 28%、SA 30%；2026-10 车队实收（市区/偏远）可达 30%–50%。塔州无独立公开指数，工具默认市区 30% / 偏远 40%（可在“费率设置”改为车队当周实收值）。
  • 与《全澳FCL尾端派送核算系统 v7》互补 — v7 覆盖除塔州/北领地外的澳洲大陆（2,696 邮编 × 20 港真实路网）；本工具专门补齐塔州 4 大集装箱港 + 120 个邮编、Bass Strait 两段式路径与岛内海运方案，两者口径一致（真实公路里程 + 基础价 + 里程费 + 燃油 + 附加）。
  • 市场费率（标注“市场假设”的项） — 基础派送费、$/km、侧卸/吊车/转运、等待、滞箱、dehire、燃油附加、Bass Strait 海运费、码头操作费等，按澳洲/塔州 FCL 拖车与货代行业常见区间校准，并在“费率设置”中开放全部系数，用户可按自身协议价替换。
重要局限：塔州本地的 wharf cartage、Bass Strait 舱位与滞箱费率均为商业协议价，不对外公开。本工具把“官方公布费率”与“市场校准假设”分层呈现，任何“市场假设”项都可以在设置页改成贵司实际协议价——改完后所有邮编报价会立即按新费率重算，从而成为贵司内部的报价引擎。
